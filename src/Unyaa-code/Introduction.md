8. 如果您主要使用**繁体**进行输入，或约40%的输入场景为繁体，建议选择其他“简繁通打”方案，本方案专为简体设计，不适合大量繁体输入

### 呜喵码入门  
**呜喵码**入门相对简单，但要熟练掌握它，仍一定的时间成本。  
新人往往会经历一段阵痛期，我们提供了一套良好的学习方案与科学训练体系，以缩短阵痛期时长。  
**入门：**
1. 如果你不会标准指法，请先练习指法  
   https://dazidazi.com/  
   https://www.keybr.com/  
2. 阅读[教程](/Unyaa-code/tutorial)了解，取码和拆分。  
3. 使用练习工具学习记忆字根，根据练习时长不同，在2-5天内完成。  
  - 练习器有两个选择：  
    1. [官网>字根循环器](/Unyaa-code/gen) 官网无需导入数据直接练习  
    2. [元素重复练习器](https://unyaa-code.github.io/root-practice/)，[GitHub地址](https://github.com/Unyaa-Code/root-practice) 独立HTML，保存到本地后可本地使用，但需导入数据
3. 练习[呜喵码必拆字](/Unyaa-code/zi)，过3遍，不追求速度，熟悉拆分即可。  
4. 使用跟打器，[木易跟打器(在线)](https://typer.owenyang.top/)、Pain打器、[极速跟打器](https://www.jsxiaoshi.com/)等练习常用单字前500  
**通用练习方法**：设置跟打器，设置发文字数为10字（或5字）一组，键准100%，击键大于等于2击下一组，若未达到2击，则乱序重打。  
刚开始练习时击键目标可设置为1-2击或更低，打过一轮后再提升0.5-1击，直至十字一组，每组能达到6击则为及格。  
<font color="#FF0000">注：练习时一定注意不要抢击，要避免积累过多错误条反，要先保证键准，重复次数多了，击键自然就上去了。</font>  

### 后续使用

- 使用跟打器，十字一组练习中五百、后五百
- 复习字根，直到形成永久记忆

[^1]: 「的、一、是、了、个」等高频汉字也不愿使用简码
