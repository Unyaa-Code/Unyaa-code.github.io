# 教程（施工中）
### 双编码
不同于五笔这类单编码方案，一个字根对应1个编码  
呜喵码是**双编码**，一个字根对应2个编码 —— 首码（大码）+ 从码（小码）  
就是一个字根由两个字母表示（或者理解为放置到两键上）  
字根第一码是什么字母（在哪个键位） 上，那它的大码就是什么  
例如，一`Fh`、日`Vi`、  
「一」的首码为``F``，从码为`h`  
「日」的首码为`V`，从码为`i`  
呜喵码的从码，少部分高频**乱序**，大部分**音托**  
- 音托：声母为 **z、y** 开头的字根，取**韵母**首字母为从码  
>如遇到无法理解的从码，当作乱序即可，无需「强迫症」过度关注  
>如果不能接受，建议您立即关闭本网站，选择其他方案    
### 字根归并
呜喵码为了降低记忆负担，减少学习难度，对部分**同源**或**形近**字根做了**归并**或**半归并**  
**归并：**  
即N个字根的首码从码完全相同  
例如：兀丌`hw`、川 巛 巜 `bc`、犬犭`qq`…  
**半归并（聚类）  ：**
顾名思义，只有一半相同  
例如：鸟**g**n 乌**g**w、土**l**c 士**l**s，首码相同，从码不同

##### 普通字根
- 字根字：Aa首笔，取字根首码+从码+字根首笔首码  
  「田**Nt**」首笔为「丨**i**s」-> `Nti`   
  「巳**Cs**」首笔为「𠃍**p**e」-> `Csp`  
  - 数字字根字，全码两码，不出简  
   二`ye`、三`ds`、四`hs`、五`kw`、六`el`、七`gq`、八`bb`、九`ej`、十`as`  
- 二根字：ABb，分别取2个根的首码+末根从码  
  「码」拆分为「石**E**s 马**Hm**」-> `EHm`  
- 三根字：ABCc，分别取3个根的首码+末根从码  
  「紫」拆分为「止**Y**i 匕**D**b **B**s」-> `YDBs`  
- 四根及以上：ABCZ，取前3根的首码+末根首码  
  「莎」拆分为「艹**C**c 氵**O**s 小**M**x 丿**W**p」-> `COMP`  
  「橘」拆分为「木**w**m 予**P**v 丿**W**p 冂Uu 八Bb 口**D**m」-> `WPWD`  
总结：拆字后，取前3根+末根首码，若首码不足四码时，则补末根从码  
##### 末根为α根
末根为：鸟、乌、隹、心，需补首根从码  
- 二根字：ABba，分别取2个根的首码+末根从码+首根从码  
  「鸹」拆分为「舌**D¹s⁴** 鸟 **G²n³**」-> `DGns`  
  「呜」拆分为「口**D¹m⁴** 乌**G²w³**」-> `DGwm`  
  「骓」拆分为「马**H¹m**⁴ 隹**N²u**³」-> `HNum`  
  「恙」拆分为「⺷**L¹a**⁴ 心**T²j³**」-> `LTjaR`  
##### 带有廴辶的字
- 二根字：ABa，补倒数第二根从码  
  「连」拆分为「车**Y¹c**³ 辶**S²**i」-> `YSc`  
  「建」拆分为「聿**W¹v³** 廴**S²**i」-> `WSv`  
- 三根字：ABCb，补倒数第二根从码  
  「莲」拆分为「艹**C¹**c 车**Y²c⁴** 辶**S³**i」-> `CYSc`  
  「键」拆分为「钅**G¹**j 聿**W²v**⁴ 廴**S³**i」-> `GWSv`  
- 四根及以上：ABCZ，与普通根一致，取一二三末根首码  
  「邀」拆分为「白**Y**b 方**Q**f 攵**O**p 辶**S**i」-> `YQOS`  

> 注：上面的字母大小写只是便于区分首码与从码。上标只是便于区分取码顺序

#### 简码
简码就是全码的前几码  
简码主要针对 常用字或词，目的是降低码长，提高打字效率  
前1码就是 一简  
前2码就是 二简  
前3码就是 三简  
一简，务必完全熟悉
二简，低频无需熟悉
三简，仅需记忆高频和出简让全

| 例字  |  全码  |  简码  |
| :-: | :--: | :--: |
|  的  | diw_ |  d_  |
|  整  | rofy | ro_  |
|  待  | yljc | ylj_ |
>注：\_代表空格
### 词组编码规则

#### 全码词
呜喵码词组规则与五笔一致  
- 二字词：分别取两个单字的前两码  
  方案 = 方**qf**k 案**ur**wm = `qfur`  
- 三字词：取前2个字的首码 + 末字的前2码  
  管理员 = 管**i**udi 理**k**gl 员**dz**b = `ikdz`  
- 四字及以上：取前3个字的首码 + 末字的首码  
  立足之地 = 立**h**lk 足**e**ui 之	**s**ik 地**l**ee = `hesl`  
  **中华人**民共和**国** = 中**a**oi 华**j**das 人**g**ew 民cgq 共xgf 和hdm 国**t**kkj = `ajgt`  
**温馨提醒**：新人先打单三个月，再自行决定是否打词！
#### 简词
新手**不要**打除「什么`jw`」以外任何简词！只有「什么`jw`」值得打  
老手也不一定要打，简词是可选项，不会影响全码打词方式  
简词就是个别高频词，口水词，选一些打，无需全打  
- 二简词：取两个字的首码  
  什么`jawg` -> `jw`  
- 三简词：取三个字的首码，三简词一定是三字词  
  怎么办`twfb` -> `twf`

### 易混项  

#### 如何区分pe和ae两种折？  
- `pe`为所有横起笔  
  乙 乁 乛 ⺄ 𠃌 𠃍 𠄎 𪛙 ㇅ ㇇ ㇊ ㇋ ㇌ ㇍ ㇎ 𘠃 𘠄 𘠅 𘲶 …
- `ae`为余下所有折  
  乚 𠃊 𠃋 𠃑 𠄌 𡿨 ㇁ ㇂ ㇃ ㇄ ㇉ ㇥ 𠃉 𬼂  𘠆 𘠇 𘯧 𘳀 𘳋…
#### 「夂 攵」 有什么区别  
夂 `oi` 、攵 `op`，这两个根很像，很多初学者会分不清  
可用2种方法区别  
1. 字形的**区别**，注意看 **右边** 是否 **出头**  
   夂 `oi` 右边**没**出头，攵 `op` 右边出头  
2. 字根的**位置**，一个在上下，一个在右  
    夂 `oi` 大部分位于 **上部 或 下部**，如：各 冬 务 条 麦 复 峻 凌  
    攵 `op` 大部分位于 **右部**，如：做 放 数 教 政 收 改 微 整 致 


### 字根认同问题  
>进阶问题，通常情况下无需过多在意  
>以下内容包含Unicode新版字符，一些设备可能显示错误（显示为框或空白等）  
#### 如何区分`口`与`囗（框）`
如果方框里有**完整**的笔画，用囗（框），否则一律用口  
为防止拆分不直观，此规定也适用于另外几个包含「口」或者封闭空间的字根：「口古合占束日目皿罒自見早」等  

#### 如何区分`日`、`曰`
如果使用形状区分，由于字体等原因，我们很难区分日和曰，如若按照字源区分，又可能会被字体误导，增加取码难度  
故我们只区有之对立的字，共四组，分别为：「日曰」、「汨汩」、「曶㫚」、「𠯐𱒈」  

#### 如何区分`子`与`孑`
只有在右部或上部的孑形才是孑，这种字比较少分别为：𰕳、𥁂、𥝔、𨥂  
如果通过字形判断是不正确的，「孔、孙、孜」等虽是是孑形，但其是子由横变提，并非孑  
「横」变「提」，具体地说，就是某些末笔为「横」或下部含有「横」的字或笔画组合，在充当某字的部件，而这个部件又处于某字（或其部件）的左旁或左下角时，它的末笔「横」，就需要改成「提」，如工—功鸿、马—骏、牛—物、车—轻等[^1]  

[^1]: [常见笔形变化规律例析](https://www.qqxiuzi.cn/wz/zixun/1516.htm)<br>[冯寿忠-汉字笔画的异质变形概观](http://www.yywzw.com/jt/feng/feng04.htm)
