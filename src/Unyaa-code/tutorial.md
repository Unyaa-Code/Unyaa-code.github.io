# （施工中）
### 双编码
不同于五笔这类单编码方案，一个字根对应1个编码  
呜喵码是**双编码**，一个字根对应2个编码 —— 首码（大码）+ 从码（小码）  
就是一个字根由两个字母表示（或者理解为放置到两键上）  
字根第一码是什么字母（在哪个键位） 上，那它的大码就是什么  
例如，一fh、日占位符、  
“一”的首码为F，从码为h  
“日”的首码为，，从码为，，  
呜喵码的从码，少部分高频**乱序**，大部分**音托**  
- 声母为 **z、y** 开头的字根，取**韵母**首字母为小码  
>如遇到无法理解的从码，当作乱序即可，无需“强迫症”过度关注  
>如果不能接受，建议您立即关闭本网站，选择其他方案    
### 字根归并
呜喵码为了降低记忆负担，减少学习难度，对部分**同源**或**形近**字根做了**归并**或**半归并**  
**归并：**  
即N个字根的首码从码完全相同  
例如：兀丌oc、川巛巜占位符oc、犬犭oc…  
**半归并（聚类）  ：**
顾名思义，只有一半相同  
例如：鸟**o**n 乌**o**w、土**o**c 士**o**s，首码相同，从码不同  
### 单字编码规则  
#### 全码
**普通字根**  
一根字：Aa首笔  
二根字：ABb  
三根字：ABCc  
四根及以上：ABCZ  
总结：拆字后，取前3根+末根首码，若首码不足四码则补从码  
**末根为α根**  
二根字：ABba  
**带有廴辶的字，取-2根从码**  
二根字：ABa  
三根字：ABCb  
> 注：上面的字母大小写只是便于区分首码与从码  
#### 简码
简码就是全码的前几码  
简码主要针对 常用字或词，目的是降低码长，提高打字效率  
前1码就是 一简  
前2码就是 二简  
前3码就是 三简  

| 例字  |  全码  | 简码  |
| :-: | :--: | :-: |
|  的  | diw_ | d_  |
|     |      |     |
|     |      |     |
|     |      |     |
>注：\_代表空格

### 词组编码规则
呜喵码词组规则与五笔一致  
二字词：分别取两个单字的前两码  
三字词：取前2个字的首码 + 末字的前2码  
四字及以上：取前3个字的首码 + 末字的首码

#### 竖向不包夹 \ 横间不穿心 \ 散件不分离  
**竖向不包夹**  
允许横向包夹，但不允许竖向包夹

| 例字  | ✅️正确拆分 | ❌️错误拆分  |
| :-: | :----: | :-----: |
|  衔  |  行 钅   |  彳 钅 亍  |
|  胤  | 儿 幺 月  | 丿 幺 月 乚 |
|  亘  | 一 日 一  |   二 日   |
|  僵  | 亻一田一田一 |  亻三田田   |
|  滚  | 氵六厶𧘇  |  氵衣八厶   |

**横间不穿心**  
为了使拆分更加直观，符合笔顺，防止字根交叉粘连，我们规定：  
“工土士干千禾王壬龶丰末未生古矢缶早羊虫”等字根的「一一」之间不允许穿插其他字根。  

| 例字  | ✅️正确拆分 | ❌️错误拆分  |
| :-: | :----: | :-----: |
|  再  | 一 土 冂  |   王 冂   |
|  垂  | 千 龷 一  |   壬 龷   |
|  禹  | 丿 虫 冂  | 丿 口 冂  |

**散件不分离**  
非连续写成、且被全包围结构或半包围结构分割的部件，不视为字根  
例如：  
“为”应拆“丶力丶”不得拆分为丷力  
#### 框类、木类结构完整  
避免框类部件被拆散，避免木类结构被拆散  

#### 根少优先  
筛选出拆分出字根数量最少的拆分方式。  
例如：“先”应拆“⺧儿不应拆分为“丿十兀”  

#### 能连不交  
筛选出字根之间相交次数最少的拆分方式  

#### 连续笔顺  
筛选出拆分最符合笔顺的方式  

#### 能散不连  
筛选出字根之间相连次数最少的拆分方式  

#### 能正不歪  
由丨变丿或乚的字根不优先使用  
- 千 变   
- 干 变   
- 丰 变   
- 羊 变 ⺶  
- 手 变 龵  
- 十 变 𠂇  
- 屮 变 䶹   
- 丅 变 丆  
- 辛 变   

#### 竖撇点折不优先  
竖、撇、点、捺、折不优先使用  
例如：  
“产”不拆“立丿”  
“严”不拆“一业丿”  

#### 取大优先  
筛选出使拆分出的第一个字根笔画数量最多的拆分方式。如果有多个拆分方式中第一个字根笔画数量都一样多，那么就再看第二个，等等。  

### 易混项  

#### 如何区分x和x2两种折？  
- `占位符2`为所有横起笔  
- `占位符`为其他所有折  
#### “夂 攵” 有什么区别  
夂 `占位符` 、攵 `占位符`，这两个根很像，很多初学者会分不清  
可用2种方法区别  
1. 字形的**区别**，注意看 **右边** 是否 **出头**  
   夂 `hi` 右边**没**出头，攵 `hp` 右边出头  
2. 字根的**位置**，一个在上下，一个在右  
    夂 `hi` 大部分位于 **上部 或 下部**，如：冬 务 条 麦 复 峻 凌  
    攵 `hp` 大部分位于 **右部**，如：效 孜 政  


### 字根认同问题  
>进阶问题，通常情况下无需过多在意  
>以下内容包含Unicode新版字符，一些设备可能显示错误（显示为框或空白等）  
#### 如何区分`口`与`囗（框）`
如果方框里有**完整**的笔画，用囗（框），否则一律用口  
为防止拆分不直观，此规定也适用于另外几个包含「口」或者封闭空间的字根：“口古合占日目皿罒自見早”等  

#### 如何区分`日`、`曰`
如果使用形状区分，由于字体等原因，我们很难区分日和曰，如若按照字源区分，又可能会被字体误导，增加取码难度  
故我们只区有之对立的字，共四组，分别为：“日曰”、“汨汩”、“曶㫚”、“𠯐𱒈”  

#### 如何区分`子`与`孑`
只有在右部或上部的孑形才是孑，这种字比较少分别为：𰕳、𥁂、𥝔、𨥂  
如果通过字形判断是不正确的，“孔、孙、孜”等虽是是孑形，但其是子由横变提，并非孑  
“横”变“提”，具体地说，就是某些末笔为“横”或下部含有“横”的字或笔画组合，在充当某字的部件，而这个部件又处于某字（或其部件）的左旁或左下角时，它的末笔“横”，就需要改成“提”，如工—功鸿、马—骏、牛—物、车—轻等[^1]
