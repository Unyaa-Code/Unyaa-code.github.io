# 思路
呜喵一代，基于宝虎拆分制作，由虎码作者B佬，操刀计算，感谢B佬  
呜喵二代，基于虎码拆分制作，由蓝宝石作者秋风，操刀计算  
呜喵三代，重新梳理拆分，并使用动态选根技术，严格意义上说，和虎码关系已经不大了  


备选字根参考：蓝宝石三代、092、091、虎码、天码、好码系列。  
拆分规则参考：天码、宇码、虎码  
取码规则参考：山人全息码、王码五笔、蓝宝石三代  


1. 廴辶取-2根小码（廴辶内最后一根）部分借鉴山人、王码五笔的取法  
   在山人中廴辶不设置小码，是直接回头取首根小码的，本人觉得在个别二根三根字中，例如连、莲，没有继承，不统一  
   在王码五笔中，带有廴辶的二根字识别码取里面字根末笔，三根字又取廴辶末笔，与山人一样，非常不优雅  
2. 字根字A a 首笔（末笔）借鉴蓝宝石三代的取码规则  
   蓝三：A 首二笔 末单笔，在此结构上首二笔替换成音托小码  
   最初的设计上字根字全码三码，为了追求离散，对首末笔离散进行了统计，粗略统计，首笔离散大概优与末笔  
3. 折笔分类方法，是来自淅码用户“eRRor·改”  
   将横起笔，与非横起笔拆分开，既做到了增加离散，又避免了顺逆不好分辨的问题  
4. 高频双乱，低频音托，借鉴露台码
